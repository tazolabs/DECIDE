Hosted evaluation

Evaluate your model.

Submit a model API. Our worker runs the private benchmark and returns aggregate accuracy by task, decision family and clip duration.

Dataset files and reference labels are not provided. Your model API operator receives the clips or transcripts and context sent for inference.

1. Submit an endpoint

Request an invitation from support@tazolabs.com with your model endpoint. Each invitation is bound to an approved HTTPS endpoint and a limited number of runs. Read the request and response contract before submitting.

Keys and invitation tokens are not saved in this browser. Only the private result receipt is saved on this device. Model providers may charge for inference; the full run sends one request per question, with bounded retries.

2. Follow your evaluation

Jobs continue after you close this page. Keep the private receipt to check results on another device. Anyone with the receipt can view or cancel that evaluation.
